# Resources

This directory is the curation layer for references that support the roadmap. It is deliberately
separate from the learning sequence so that a source can be updated without turning the curriculum
into a link catalog.

## Selection criteria

A resource earns inclusion when it is authoritative, technically accurate, relevant to a stated
learning outcome, and more useful than the existing references. Primary documentation, standards,
original papers, and well-maintained implementation guides are preferred.

Each future resource entry should record:

- the title, author or maintaining organization, and canonical link;
- the learning outcome or decision it supports;
- why it was selected over likely alternatives;
- required background and the sections worth prioritizing;
- publication or version information and, for time-sensitive material, the review date;
- access, license, cost, registration, or compute constraints.

## Quality controls

- Link to the canonical source instead of copying substantial material.
- Separate durable references from version-specific procedures.
- Do not present popularity as evidence of correctness.
- Replace superseded guidance while preserving a note when the change affects the curriculum.
- Review security, API, pricing, and version claims before relying on them in exercises.
- Remove a broken source only after identifying whether an authoritative replacement exists.

## Boundaries

This directory is not a dumping ground for bookmarks, vendor marketing, or undifferentiated reading
lists. A resource without a declared purpose and maintenance context does not meet the repository's
evidence standard.

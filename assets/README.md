# Assets

This area will hold diagrams, screenshots, and images that materially improve learning content.
Assets must be maintainable, accessible, legally reusable, and traceable to their source.

## Planned layout

| Area | Purpose |
| --- | --- |
| `diagrams/` | Editable architecture and workflow source plus rendered output when needed |
| `screenshots/` | Product or lab screens that clarify a step or expected result |
| `images/` | Supporting illustrations that cannot be expressed clearly in Mermaid or code |

## Asset contract

Every committed asset must have a descriptive filename, meaningful alt text at its use site, and a
clear reason it is better than prose or Mermaid. Source, author, license or permission, creation
date, and editable source should be recorded when applicable.

Screenshots must exclude credentials, tokens, personal data, private URLs, tenant identifiers, and
confidential business information. Crop irrelevant interface chrome and ensure text remains legible.

Do not copy branding, diagrams, or imagery from reference material unless repository reuse rights are
explicit. Concepts may be re-expressed in original diagrams with appropriate source attribution.
